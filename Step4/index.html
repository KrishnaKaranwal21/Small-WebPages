Exam strategy

  • Read constraints first. n ≤ 10^5 means aim for O(n) or O(n log n); n ≤ 10^3 allows O(n²).
  • Say brute force first, then name the pattern that improves it. Examiners reward the reasoning.
  • Edge cases: empty array, single element, all equal, negatives, duplicates, overflow of window/pointers.
  • Pattern cues: sorted → two pointers/binary search • "pair/complement" → hash map • "contiguous sum" → prefix sum or sliding window • "next greater" → monotonic stack • "max reachable/locally best" → greedy.
  • Python helpers: Counter, defaultdict(list), enumerate, bisect_left, heapq, list.sort(key=...).
  • Always state time and space complexity at the end, and dry-run on a tiny example.
